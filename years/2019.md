# 2019 Publications

[Year Index](README.md) · [Browse by Category](../catalog/README.md) 

ImageCLEF VQA-Med 2019 divided radiology questions into four groups: imaging modality, imaging plane, organ system, and abnormality. The first three tend to have a limited set of answers. Abnormality questions allow more varied wording, so the score depends in part on how the evaluation handles that variation. The challenge reported both exact accuracy and BLEU, which measures overlap with a reference answer. The questions were designed to be answered from the image without consulting the patient's record. The other paper on this page, *Overcoming Data Limitation in Medical Visual Question Answering*, asks how to train a model when few images have question and answer labels. Its method, MEVF, learns image features in two ways: it uses meta-learning on small medical image tasks and learns to reconstruct images from noisy inputs. The model combines these features with the question and selects an answer from a fixed set on VQA-RAD. That detail is easy to miss when a dataset calls its questions open-ended: the model can still be choosing a label instead of writing an answer. The two papers use different evaluation setups. Their scores should be read alongside the question types, answer choices, and scoring rules used in each study.
